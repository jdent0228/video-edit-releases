# Video Editor by Dr.J — 다운로드

간단하고 빠른 영상 편집기입니다. 자르기·이어붙이기, 음악 멀티트랙, 자동 자막,
화면 배치 편집, 분할 저장을 지원하며 모든 처리가 컴퓨터 안에서 이루어집니다
(영상이 외부로 전송되지 않습니다).

## 다운로드

**[👉 최신 버전 다운로드 (Releases)](https://github.com/jdent0228/video-edit-releases/releases/latest)**

| 운영체제 | 파일 |
| --- | --- |
| macOS (Apple Silicon, M1 이후) | `Video.Editor.by.Dr.J-….dmg` |
| Windows (64비트) | `Video.Editor.by.Dr.J.Setup.….exe` |

릴리스 페이지 맨 아래의 `Source code` 링크는 GitHub가 자동으로 붙이는 것으로,
이 저장소의 안내 문서만 들어 있습니다 (프로그램 소스 코드가 아닙니다).

## 설치 방법

**macOS**
1. dmg를 열고 앱을 `응용 프로그램` 폴더로 드래그
2. 서명이 없는 앱이라 처음 한 번만 터미널에서:
   ```
   xattr -cr "/Applications/Video Editor by Dr.J.app"
   ```

**Windows**
1. Setup.exe 실행 (자동 설치)
2. SmartScreen 경고가 뜨면 **추가 정보 → 실행**

## 첫 실행

처음 실행하면 **비밀번호**를 묻습니다. 비밀번호는 배포자에게 받으세요.

## 업데이트

새 버전이 나오면 앱 오른쪽 위에 **업데이트** 버튼이 나타납니다. 누르면:
- **macOS**: 새 버전을 내려받아 자동으로 교체 후 재시작
- **Windows**: 이전 버전과 달라진 부분만 내려받아 자동 설치 후 재시작

## 주요 기능

- 자르기 / 이어붙이기 / 비파괴 트리밍(빈 구간 + 휴지통)
- 화면 배치 편집 (이동·크기·크롭), 회전·반전, 배속 0.25~4×, 색 보정
- 음악 멀티트랙(3), 원본 소리 토글, 페이드
- 자동 자막 (음성 인식, 한국어 지원, 기기 내 처리)
- 텍스트 자막, 화면 전환, 분할 저장(파일 탭)
- MP4/H.265/WebM/GIF/MP3, 하드웨어 가속 인코딩
- 4K·장시간 영상 지원, 자동 저장·복원
